🧪 InventoryLab API
Простая система учета реактивов и мест хранения для лаборатории.

🚀 Быстрый запуск
1. Установка
bash
# Создайте виртуальное окружение
python -m venv venv

# Активируйте (Windows)
venv\Scripts\activate

# Активируйте (Mac/Linux)
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
2. Запуск
bash
# Перейдите в папку app
cd app

# Запустите сервер
uvicorn main:app --reload
Приложение доступно по адресу: http://localhost:8000

📖 Документация
Откройте в браузере: http://localhost:8000/docs

В Swagger UI вы можете:

Видеть все доступные эндпоинты
Нажимать "Try it out" для тестирования
Заполнять формы прямо в браузере
Получать ответы от API

🔧 Основные возможности

Реактивы (/reagents)
Добавить реактив - автоматически подбирает место хранения
Просмотреть все - список всех реактивов
Найти по ID - информация о конкретном реактиве
Обновить - изменить данные реактива
Удалить - удалить реактив
Списать - уменьшить количество реактива
Найти просроченные - реактивы с истекающим сроком
Фильтровать - поиск по различным параметрам
Места хранения (/storage)

Добавить место - создать новое место хранения
Просмотреть все - список всех мест
Активные места - только активные хранилища
Найти по ID - информация о конкретном месте
Найти по имени - поиск по названию
Обновить - изменить данные места хранения
Проверить использование - сколько места занято
Получить рекомендацию - куда положить реактив определенного класса опасности
Просмотреть с реактивами - место хранения со списком реактивов в нем

📝 Быстрый старт через Swagger UI
1. Создайте места хранения
Откройте http://localhost:8000/docs

Найдите POST /storage/storage-locations
Нажмите "Try it out"
Заполните форму с полями:

json
{
  "name": "Холодильник лабораторный",
  "type": "refrigerator",
  "max_capacity": 20,
  "is_active": true
}
Нажмите "Execute"

2. Добавьте реактив
Найдите POST /reagents
Нажмите "Try it out"
Заполните форму с полями:

json
{
  "name": "Серная кислота",
  "formula": "H2SO4",
  "cas_number": "7664-93-9",
  "quantity": 500,
  "unit": "ml",
  "hazard_class": 2,
  "expiry_date": "2024-12-31"
}
Нажмите "Execute" - система сама подберет подходящее место хранения!

3. Проверьте результат
GET /reagents - увидите все реактивы

GET /storage/storage-locations - увидите все места хранения

GET /storage/storage-locations/{id}/with-reagents - увидите какие реактивы в каком хранилище

Особенности системы
Автоматический подбор хранилища
При добавлении реактива система автоматически находит подходящее место хранения по классу опасности:

Класс 1 → Сейфы

Классы 2-3 → Холодильники/морозильники

Класс 4 → Обычные шкафы

Встроенные проверки

CAS номер должен быть уникальным
Дата годности не может быть в прошлом
Нельзя списать больше чем есть
Нельзя превысить вместимость хранилища
Проверка соответствия класса опасности и типа хранения

Важные моменты

CAS номер должен быть уникальным для каждого реактива
Класс опасности от 1 (самый опасный) до 4 (наименее опасный)
Срок годности не может быть прошедшей датой
Единицы измерения: ml, l, g, kg
Типы хранилищ: cabinet, refrigerator, freezer, safe

async def create_tables():
    async with engine.begin() as conn:
        await conn.run_sync(Model.metadata.create_all)

async def delete_tables():
    async with engine.begin() as conn:
        await conn.run_sync(Model.metadata.drop_all)
Разберем построчно:
async with engine.begin() as conn:

engine - наш "движок" базы данных

begin() - начинаем транзакцию (пачку операций)

conn - соединение с базой данных

async with - автоматически закрывает соединение после работы

await conn.run_sync(Model.metadata.create_all)

Model.metadata - содержит информацию о ВСЕХ наших таблицах

create_all - создать все таблицы

run_sync - запустить синхронную функцию в асинхронном контексте

await - ждем завершения операции
